# 自定义表达式规则详解

表单引擎支持多种"自定义表达式"，用于控制隐藏、禁用、颜色、日期、赋值、翻译等场景。**表达式有几种不同的包裹标记，语义完全不同，生成 JSON 时务必区分。**

---

## 一、表达式的"括号标记"规则

### 1. 花括号 `{xxx}` —— 自定义表达式（自动带 return）

- **格式**：`{XXX}` 或 `{xxxxxx}`
- **是否需要写 return**：**不需要**，表达式会**自动附带 return**，需要返回一个值。
- **示例**：`{jsonData.formData.XXX}` 返回主表 XXX 字段的值。
- **适用场景**：隐藏/显示判断、确认框/提交框、行权限、按钮内容、字体/背景颜色条件等。

### 2. 方括号 `[xxx]` —— 三种不同含义（务必区分！）

#### 含义 A：`[XXXXXX]` 自定义表达式（需自行加 return）

- **是否需要写 return**：**需要自行写 return**（与花括号相反）。
- **可用参数**：`jsonData`（模板数据）、`table`（对应配置的表格数据）。
- **示例**：
  - `[return jsonData.formData.XXX]` —— 返回主表 XXX 字段的值
  - `[if(jsonData.formData.XXX)return '1';return '']` —— 主表 XXX 有值返回 `'1'`，否则返回 `''`
- **出现位置**：表格添加行的"默认值"配置、导出文件名称等。

#### 含义 B：`[X,XX,XXX]` 字段名列表 —— 判断字段是否在列表内

- **格式**：`[XXXX,XXX,XX,X]`，里面是字段名称列表。
- **含义**：判断当前配置了 value 属性的字段名是否**存在于该列表内**；存在返回 true，不存在返回 false。
- **出现位置**：字体颜色 / 背景颜色（anyColorSetting）的规则 6。

#### 含义 C：`[XXX]` 取子表数据（日期禁用场景）

- **格式**：`[XXX]`，XXX 为**子表的表格名称**。
- **含义**：取子表 `tableData.XXX` 数组，遍历其中固定字段名为 `date` 的字段值，作为禁用日期列表。
- **出现位置**：日期组件"禁用配置"（disabledDate）。

### 3. `{X}` 特殊标记 —— 转为空字符

- `{X}` 是特殊标记，会**特定转为空字符 `""`**。
- 在 `{XX+XXX}` 拼接表达式中，如果字段名找不到，返回原表达式 `XX+XXX`；而 `{X}` 会特定转为空字符。

### 4. `$index` 特殊标记 —— 行下标序号

- **含义**：子表/表格的**当前行下标**。
- **两种用法**：
  - 作为表达式参数：`$index` = 子表当前行下标（无则为空或 0）。
  - 序号格式（lineid 的 indexFormat）中：`$index` 关键字转换为**从 1 开始自增的序号**，如 `NO$index` → `NO1,NO2...`。

### 5. `${xxx}` 特殊标记 —— 语言翻译表达式

- **格式**：`${xxx}`，xxx 为自定义表达式，需要返回值，自动附带 return。
- **可用参数**：`jsonData`、`col`、`row`、`value`。
- **出现场景**：国际化/语言翻译配置。

### 6. 字段名称直接配置（无括号）

- 直接填字段名称，读取该字段值进行判断。
- 不同场景"有值/无值"的效果不同（见下文）。

## 二、表达式内置可用参数

| 参数 | 含义 |
|------|------|
| `jsonData` | 当前模板的所有节点 json |
| `jsonData.formData` | 主表数据（主表字段通过 `jsonData.formData.字段名` 访问） |
| `jsonData.tableData` | 子表数据（`jsonData.tableData.表名`） |
| `formData` | 主表数据（简写） |
| `tableData` | 子表数据（简写） |
| `col` | 当前配置（当前按钮/列的配置对象） |
| `row` | 表格当前行数据 |
| `rowData` | 当前最上级行的配置信息 |
| `ele` | 当前子表行数据（多用于 `set(ele,key,value)`） |
| `value` | 原本字段名称对应的值 |
| `result` | 快速计算结果值（或后表达式中后端模型返回结果） |
| `data` | 选中的列表数据（数组，弹窗确认执行前校验场景） |
| `action` | 当前单个执行的逻辑 action（后表达式场景） |
| `date` | 日期组件的每个日期（日期禁用场景） |
| `table` | 对应配置的表格数据（`[]` 表达式内） |
| `$index` | 子表当前行下标 |
| `set` | 内置深度赋值函数，格式 `set(ele,key,value)` |
| `$message` / `$alert` / `$confirm` / `$prompt` / `$msgbox` / `$notify` | element-ui 提示信息封装函数 |

### `set(ele, key, value)` 深度赋值函数

- **格式**：`set(ele,key,value)`
- **示例**：`set(jsonData.formData,'XXX',value*10)` —— 主表 XXX 字段的值乘以 10 并赋值回去。
- **出现场景**：输入定义、后表达式、执行前校验等所有"无 return、需赋值"的表达式场景。

## 三、条件判断语法限制

1. **不能使用 if-else**：所有自定义表达式**不适合使用 `(if-else)` 条件判断语法**。
2. **用三元 `?:` 代替**：统一用 `(?:)` 三元运算符。
3. **true/false 语义因场景而异**（务必按场景区分）：

| 场景 | 返回 true / 有值 | 返回 false / 无值 |
|------|------------------|-------------------|
| 隐藏（hiddenCol） | 不隐藏（显示） | **隐藏** |
| 权限/编辑权限 | **允许编辑** | 不允许编辑 |
| 确认框/提交框（before） | **触发确认框/提交框** | 不触发 |
| 执行前校验（before） | **阻止后续操作，弹窗** | 不阻止 |
| 执行校验（actionBefore） | **阻止该逻辑执行** | 继续执行 |
| 字体/背景颜色条件 | **显示该颜色** | 不显示 |
| 左侧选项框禁用 | **不禁用** | 禁用 |

---

## 四、各场景表达式规则差异

### 1. 隐藏（hiddenCol）与禁用（disabled）

**隐藏（hiddenCol）**：
- 直接填字段名：有值则隐藏，无值则显示。
- `{XXX}` 表达式：自动带 return；返回 true/有值 → 不隐藏；false/空 → 隐藏。
- **注意**：表达式与直接填字段名的方式**效果正好相反**。

**禁用（disabled）**：
- 有值则禁用，空值则不禁用。
- `{XXX}` 表达式：返回 true/有值 → 不禁用；false/无值 → 禁用。

### 2. 字段标题（title）与显示文本（text）

- **按钮内容/显示文本**：静态文本 / `{XXX}` 花括号自定义返回值（自动带 return，返回值即显示内容）。
- **文本定义（显示型 textExpress）**：**不加 `{}`**，自动附带 return，返回值即文本框显示内容。
- **输入定义（赋值型 inputVerify）**：**没有 return**，需写等式或 `set()` 方法，如 `set(jsonData.formData,'XXX',value*10)`。

### 3. 日期禁用（disabledDate / disabledDateExpress）

**禁用配置（disabledDate）**——静态/取数：
- 静态日期：`"2023-11-05,2023-11-06"`（逗号隔开）。
- `{XXX}`：取主表 XXX 字段的值作为禁用日期。
- `[XXX]`：XXX 为子表表格名，取 `tableData.XXX` 数组遍历字段 `date` 的值。

**禁用定义（disabledDateExpress）**——自定义表达式：
- 直接写条件，**无需 return**，if-else 用 `?:`。
- 可用参数：`jsonData`、`col`、`row`、`date`。
- 示例：
  - 禁止选择今天之前：`date.getTime() < Date.now() - 86400000`
  - 禁止选择今天之后：`date.getTime() > Date.now() - 86400000`

### 4. 字体/背景颜色（anyColorSetting）

7 条规则（颜色条件）：

1. 静态颜色。
2. 直接填字段名：值空 → 不显示；非空 → 显示。
3. `!XXX` 取反：值空 → 显示；非空 → 不显示。
4. `{xxxxxx}` 自定义表达式（自动带 return，用 `?:`）。
5. 返回 true/有值 → 显示；false/空 → 不显示。
6. `[XXXX,XXX,XX,X]`：字段名在列表内 → 显示，否则不显示。
7. 多颜色用数组 `anyColorSetting`，每项 = 一个颜色 + 一条规则。

### 5. 快速计算（formula / quickCalc）

- 用字段名称的加减乘除表达式计算结果并赋值。
- 示例：`A+B-C*D/E` 或 `(A+B-E)*C/D`，A、B、C、D、E 均为字段名称。
- 计算结果作为 `result` 参数供其他表达式引用。

### 6. 序号格式（lineid 的 indexFormat）

1. `$index` 转为从 1 开始自增序号，`NO$index` → `NO1,NO2...`。
2. 多个表达式用逗号隔开，`NO,$index` → `NO1,NO2...`。
3. `{XXX}` 转为主表 `jsonData.formData.XXX` 的值。
4. `[XXX]` 转为子表当前行 XXX 字段的值。

### 7. 语言翻译（language）

- 翻译标识 `lang`：翻译 KEY，可自定义；可用 `${xxx}` 表达式。
- 翻译文本：`{zh:中文,en:English,...}` 格式；`[语言标识]` 对应翻译值。

### 8. 公式赋值（formula）

- 用 `.` 定义多层级关系，`=` 号必填。
- 基本格式 `A.B.C=data.Table`；例 `formData.DOCNUM=data`、`status.data=data.Table`；多个用逗号隔开。

---

## 五、核心记忆点

1. **`{}` 自动带 return，`[]`（含义A）需自己写 return** —— 这是最容易混淆的点。
2. **`[]` 有三种含义**：自定义表达式（写 return）、字段名列表判断、子表取数。
3. **条件判断不能用 if-else，只能用三元 `?:`**。
4. **`{X}` 是特殊标记，转为空字符 `""`**。
5. **true/false 的语义因场景而异**（隐藏、权限、颜色、禁用等场景效果相反）。
6. **内置参数**：`jsonData`/`jsonData.formData`（数据）、`col`/`row`/`value`/`$index`（上下文）、`set()`（赋值）、`$message` 等（提示）。
