# 交付前检查清单

生成 HTML 与 PDF 后按本清单自检。**发现问题时保留原文并在交付说明中列出，不要静默修改内容。**

## 内容完整性

- [ ] 源 Markdown 以只读方式读取，未被覆盖、移动、重命名
- [ ] 措辞、顺序、标题层级、列表、表格、代码、图片、公式、引用、脚注、任务状态全部保留
- [ ] 新增的封面、目录、页眉页脚、卡片、元信息明确属于排版层，未冒充原文
- [ ] **未自动删除任何重复内容**（重复只报告，不处置）

## 类型与结构

- [ ] 文档类型已自动判定，且判定结果与依据记录在交付说明中
- [ ] 判定存疑时已标注「类型判定存疑」
- [ ] 标题层级语义正确，无无谓跳级
- [ ] 目录链接指向稳定锚点
- [ ] 表格使用真实 table 语义，表头可读
- [ ] 代码、图、引用、脚注、任务清单结构保留

## 打印与 PDF

- [ ] A4 尺寸与页边距已显式声明
- [ ] 分页位置有意图，标题不与其后内容分离
- [ ] 表格跨页重复表头，行不被无意义切断
- [ ] 图片与 SVG 尺寸有界，颜色适合打印
- [ ] 打印预览无水平溢出
- [ ] **页码缺失已在交付说明中标注**（Chrome headless 固有限制）
- [ ] PDF 实际生成的页数与内容范围合理

## 中文阅读

- [ ] 本地字体回退链存在，无远程字体依赖
- [ ] 长中文段落已两端对齐
- [ ] 行距、段距、行宽舒适
- [ ] 标题、标签、代码、短 UI 文本未被强制两端对齐

## 安全与可移植性

- [ ] 未把不受信任的原始 HTML 或脚本未经净化直接纳入页面
- [ ] 核心阅读与打印不依赖任何远程资源
- [ ] 本地图片与 SVG 路径有效，或已明确报告失效项
- [ ] Mermaid / Graphviz 转换状态如实标注，未伪造图形
- [ ] 输出可从本地文件直接打开，无需开发服务器
